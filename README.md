# FitForge V6.1 — Personal Nutrition and Exercise Library

Run `index.html` with VS Code Live Server.

## New in V4
- Settings page
- English / Spanish preference
- Pounds / kilograms preference
- Light / dark theme
- Real recipe photography in the recipe catalog
- Real exercise photography in the workout library
- Unit-aware weight display and entry
- 100 complete recipes with preparation and cooking times
- Detailed step-by-step instructions and practical cooking tips
- 100 exercises across six muscle groups
- Improved recipe cards, detail layout, keyboard focus and mobile presentation
- Premium dark dashboard design inspired by modern fitness apps
- Recipe search and full exercise detail views
- Recipe and exercise favorites with nutrition filters
- Automatic weekly meal-plan generation and shopping list
- Exercise-specific images loaded from the public-domain Free Exercise DB
- Primary and secondary muscle visualization for exercise details
- Simplified experience focused on recipes, meal planning and exercise variety

## Note about images
Recipe and exercise images are loaded from external web URLs, so the browser needs an internet connection for them to appear. This is intentional for the consumer preview. A later production version should store licensed/approved image assets locally or in app storage/CDN.

Data stays in browser localStorage under `fitforge_v3`, so your V3 consumer-preview data can continue to appear in V4.
